# Safety and originality compliance checklist

## Originality
Do not present this as `Escape From Tarkov` on Roblox, copy Tarkov's map layouts/trader names/scav faction names, directly reproduce screenshots/UI, import extracted gun models, use Battlestate/reissad logos, sample music/gunshots or suggest affiliation. Develop new world lore and brand. Use game references as design analysis only; gameplay ideas are inspiration, not a license to copy expressive assets.

## Roblox content/maturity
Combat/fictional weapons are possible, but Roblox requires accurate maturity/compliance questionnaire. Default visual direction: bloodless/non-graphic impacts, bodies fall or disappear instead of detailed death imagery; no gore, torture, graphic injuries, hate symbols or real-life atrocities. If realism leads to stronger violence, owner must assess resulting age restrictions and location restrictions before publishing. Avoid UI text that glorifies real-world mass violence. Roblox current Creator Hub has labels Minimal/Mild/Moderate/Restricted, country-specific restrictions and stricter asset moderation; verify current policy during release.

## Data/privacy & purchases
No player-generated uncensored text fields in M1; no private user info collected. Do not expose user IDs in public HUD. Chat behavior remains Roblox filtering system. No real-money gambling/lootboxes or pay-to-win gear advantage. Respect attribution/licenses for any sourced audio/graphics.

## Owner release gate
Claude should produce asset provenance manifest, IP checklist, questionnaire answers **for owner review**, console-readiness report and no auto-publish. User must approve final publishing, category/age disclosures, purchases and any live migrations.
